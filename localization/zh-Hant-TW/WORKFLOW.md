# 繁中工具目錄維護流程

## 狀態

- `not_started` 尚未開始
- `draft` 已有不完整草稿
- `translated` 已完成第一輪翻譯，等待審查
- `reviewed` 已完成語言與領域審查
- `stale` 英文來源已有變更，需要重新核對
- `blocked` 因授權、術語或來源問題暫停

## 翻譯原則

1. 工具、專案、模型與資料集名稱不翻譯
2. 保留原始分類、排序、網址與技術限制
3. 不自行宣稱工具安全、有效、持續維護或支援繁中
4. `open source` 譯為「開放原始碼」，`open weight` 譯為「開放權重」
5. `hash matching` 譯為「雜湊比對」，`red teaming` 譯為「紅隊測試」
6. `moderation` 依語境譯為「內容治理」或「內容審查」
7. 原文列出非開源服務時，保留其非開源說明

## 更新工具項目

1. 從最新 `upstream/main` 核對英文來源
2. 在英文清單確認分類、字母排序、原始碼連結與描述
3. 同步更新繁中名稱列、描述、網址及分類
4. 比較英文與繁中工具項目筆數
5. 更新 `sources.tsv` 的來源 commit 與狀態
6. 執行 `./localization/zh-Hant-TW/scripts/check.sh`
7. 由語言審查者與領域審查者分別確認

## 採用前核對

本目錄只協助發現工具。小型社群在試用或導入前，至少應另外核對下列事項。

- 授權是否允許預定使用與修改方式
- 最近一次發行與維護狀態
- 是否會將內容或個人資料傳送給第三方
- 是否需要處理兒少性影像、私密影像或其他高風險資料
- 模型訓練語言與繁中測試結果
- 誤判、漏判、申訴與人工複核流程
- 執行所需的基礎設施、成本與維護能力
